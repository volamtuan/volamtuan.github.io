📄 Script .sh cài đặt proxy

            

            

                Ghi chú: các bạn cần thay các phần YOUR_PUBLIC_IP(nếu có) để script hoạt động được, nhớ bỏ dấu \ mỗi chỗ
                có \$, phần đổi
                ip sau thời gian quy định không có hiệu lực
                trong script này. Script này chạy trên Ubuntu, có mạng ipv6 là eth0. Bạn có thể cho hết script trên vào một file
                .sh bất kỳ, đưa lên github hoặc trang web
                của
                bạn để lấy link (Ví dụ link file là: https://webcuatui.com/script.sh).

                Trên VPS Ubuntu của bạn, chạy dòng lệnh sau để tự động cài đặt proxy với dữ liệu bạn đã điền: 
bash <(curl -sSL "https://webcuatui.com/script.sh" )

                        Nếu nhà cung cấp vps hỗ trợ startup script, lúc tạo vps, bạn có thể điền nội dung phần startup script như
                        sau để khi vps tạo xong sẽ tự động chạy script sh:

                        #!/bin/bash

                            curl -sSL https://webcuatui.com/script.sh | bash
